Inside the fly
Every dot is one of 166,700 neurons. Each frame is one character: 120 ms of simulated time.
Send a prompt to watch GPF-1's neurons fire.
Each letter switches on its own set of projection neurons (PN). They excite a few Kenyon cells (KC), the fly's sparse memory code. The memory's output neurons (MBON) rarely fire, which is why the fly remembers only the last few letters.
